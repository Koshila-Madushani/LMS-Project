# AURAPEN LMS - Learning Management System

A web-based Learning Management System (LMS) designed and developed to streamline educational management, teacher schedules, student progress tracking, and study material distribution.

Developed as a Final Year Project for the Higher National Diploma in Information Technology (HNDIT).

---

## Tech Stack

- Frontend: React.js, HTML5, CSS3, JavaScript (ES6+)
- Backend: Node.js, Express.js
- Database: MySQL
- Version Control: Git & GitHub

---

## Key Features

- User Authentication: Secure login system for Admins, Teachers, and Students.
- Teacher & Class Management: Schedules, timetables, and teacher reports tracking.
- Learning Materials: Chapter-based PDF upload and resource sharing.
- Quizzes & Question Bank: Interactive quizzes and teacher feedback modules.
- Dashboard: Clean dashboard UI for managing overall institute operations.

---

## How to Run the Project Locally

1. Clone the repository:
   git clone https://github.com/Koshila-Madushani/LMS-Project.git

2. Navigate to project directory:
   cd LMS-Project

3. Install dependencies:
   npm install

4. Start the Frontend Application:
   npm start

5. Start the Backend Server:
   node server.js
